## Установка

Нужен Мак на Apple Silicon (M1 и новее) с macOS 26 или новее.

Проще всего поручить установку ИИ-агенту (Claude Code, Codex и т.п.). Вставьте ему:

```text
Установи последний стабильный релиз Insomnia по инструкции https://github.com/ungurenko/Insomnia/blob/main/skills/install-insomnia/SKILL.md. Если для шага нужен мой пароль, дай мне команду, которую я выполню в Терминале.
```

Установить самому: [docs/install.md](docs/install.md) (на английском). Там же
описано, как проверить, что скачанный архив собран из этого репозитория.

При первом запуске macOS может сказать, что не может проверить разработчика:
приложение подписано без платного сертификата Apple. Откройте
«Системные настройки» → «Конфиденциальность и безопасность» и нажмите
«Всё равно открыть» напротив Insomnia.

Если у вас стоит оригинальная Insomnia, установщик заменит её. macOS считает
русскую версию другим приложением, поэтому доступ к геолокации и автозапуск
придётся включить заново.

### Сборка из исходников

Нужен Xcode со Swift 6.2 или новее. Вместо `v<version>` подставьте номер
последнего релиза:

```bash
git clone --branch v<version> --depth 1 https://github.com/ungurenko/Insomnia.git
cd Insomnia
./scripts/install.sh
open "$HOME/Applications/Insomnia.app"
```

<details>
<summary><strong>Что установщик меняет на Маке</strong></summary>

Установщик попросит пароль, потому что правило sudoers лежит в системной
папке. Он ставит:

- Само приложение в `~/Applications/Insomnia.app`.
- **Агент восстановления**: задание `launchd`, которое запускается раз в минуту.
  Если приложение пропало к моменту, когда сессия должна закончиться, агент
  пробует откатить её изменения.
- **Правило sudoers** в `/etc/sudoers.d/insomnia`. Оно разрешает вашей учётной
  записи (любой программе от вашего имени, не только Insomnia) выполнять без
  пароля четыре команды:

```text
/usr/bin/pmset -a disablesleep 1
/usr/bin/pmset -a disablesleep 0
/usr/bin/pmset -b lowpowermode 1
/usr/bin/pmset -b lowpowermode 0
```

Прочитайте правило до установки. Полный список файлов и порядок обновления:
[docs/install.md](docs/install.md#what-gets-installed).

</details>

## Как пользоваться

1. **Быстрый старт.** Кликните по глазу в строке меню и выберите готовое время.
   «Своё время…» открывает поля для дней, часов и минут, затем нажмите Enter.
2. **Добавить время.** Кликните по глазу во время сессии и выберите «+ …».
3. **Закончить раньше.** «Остановить сейчас» в меню глаза или долгое нажатие на
   кнопку рядом с отсчётом.
4. **Настройки и статус.** Правый клик по глазу. «Выйти» сначала откатывает
   изменения сессии и не даст выйти, пока что-то ещё ждёт отката.

Закрывать крышку необязательно, а открытие крышки не заканчивает сессию.

От батареи Insomnia включает режим энергосбережения ниже 40% и заканчивает
сессию ниже 10%. Оба порога меняются в настройках, порог 0 отключает
завершение по батарее. При сильном нагреве включается энергосбережение,
при критическом сессия заканчивается. Эти правила работают, только пока
приложение запущено.

Перед первой сессией загляните в настройки, потом запустите короткую сессию
под присмотром и прочитайте `~/Library/Logs/Insomnia/insomnia.log`.

## Что происходит при закрытой крышке

Во время сессии закрытие крышки делает следующее, а открытие пробует всё
вернуть. Таймер продолжает идти.

- **Гаснут экран и подсветка клавиатуры.** Insomnia сначала запоминает их яркость.
- **Приложения из списка заморозки замораживаются** (`SIGSTOP`, до `SIGCONT`
  при открытии). В списке по умолчанию Slack, WhatsApp и Discord.
  «Замораживать все остальные приложения» выключено и даже включённое не трогает
  приложения для звонков, записи и диктовки.
- **Выключается звук.** При открытии крышки звук возвращается на каждом выходе,
  который Insomnia выключила.
- **Включается энергосбережение.** Выключается при открытии, если его не держит
  правило батареи или нагрева.
- **Docker Desktop замораживается, когда не работает ни один контейнер.**
  По умолчанию выключено.

На ноутбуках Mac с Apple Silicon или чипом T2 закрытая крышка аппаратно
отключает встроенный микрофон. Чтобы записывать встречу с закрытой крышкой,
нужны AirPods или внешний микрофон.

Подробности: [docs/lid-close.md](docs/lid-close.md).

## Как работает восстановление

Insomnia записывает каждое изменение в **журнал восстановления** на диске
до того, как его сделать. Конец сессии откатывает всё из журнала. Если
приложение упало или закрылось, агент восстановления сделает то же самое после
времени окончания сессии.

Что требует вашего участия:

- Агент не умеет возвращать звук. Для этого снова откройте Insomnia.
- Агент не следит за батареей и температурой.
- Insomnia размораживает только процессы, которые точно заморозила сама.
  Остальные остаются замороженными, пока вы их не проверите.

Если в меню появилось предупреждение о восстановлении, разберитесь с ним, прежде
чем оставлять Мак. Все случаи описаны в [docs/recovery.md](docs/recovery.md).

## Дополнительно

<details>
<summary><strong>Переключение на хотспот iPhone и tmux</strong></summary>

Если во время сессии пропал Wi-Fi, Insomnia может подключиться к хотспоту
iPhone. В «Системных настройках» → Wi-Fi поставьте «Подключаться к точкам
доступа» на «Автоматически», затем введите имя и пароль хотспота в настройках
Insomnia. Пароль хранится в связке ключей. Insomnia попросит доступ к
геолокации: без него macOS не показывает названия сетей. Само местоположение
приложение не читает. После переустановки пароль нужно ввести заново.

Через 90 секунд без сети Insomnia может напечатать `continue` в панель tmux,
где работает ИИ-агент. Только в панели, которые вы указали в настройках и
отметили сами:

```bash
tmux set-option -p -t <session:window.pane> @insomnia-nudge on
```

Подробности: [docs/extras.md](docs/extras.md).

</details>

<details>
<summary><strong>Chrome, Chromium и Arc</strong></summary>

Эти браузеры замедляют скрытые окна, а при закрытой крышке скрыты все окна.
Если браузер запущен без нужных флагов, в меню по правому клику появится
«Перезапустить [браузер] без замедления». Insomnia сначала спросит: перезапуск
закрывает браузер, и вкладки вернутся, только если он умеет открывать их
при запуске.

</details>

<details>
<summary><strong>Настройки и приватность</strong></summary>

Настройки лежат в `~/Library/Application Support/Insomnia/config.json`, логи в
`~/Library/Logs/Insomnia/`. Доступ к ним есть только у владельца. В логах могут
быть названия сетей Wi-Fi, процессы и панели tmux, поэтому проверьте лог,
прежде чем кому-то его отправлять.

</details>

## Удаление

Из папки с исходниками:

```bash
./scripts/uninstall.sh          # удаляет приложение, агента и правило sudoers
./scripts/uninstall.sh --purge  # плюс настройки и логи
```

Из распакованного архива релиза запустите `./uninstall.sh` в его папке.
Сначала он откатывает открытую сессию и останавливается, если не может.
